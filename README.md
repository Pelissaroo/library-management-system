# library-management-system
A library management system built with Java to practice object-oriented programming, business rules, and software architecture.

## Features

- Register books
- List books
- Register users
- List users
- Interactive console menu
- - Book loan registration


## Next Features

- Return borrowed books
- List active loans

## Technologies

- Java
- Object-Oriented Programming (OOP)
